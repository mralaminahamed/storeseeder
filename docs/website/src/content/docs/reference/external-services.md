title: External services
description: What is fetched, when, and on whose say-so.
---

StoreSeeder contacts GitHub for sample data and for recipes, and WordPress.org for the author's other
plugins. Nothing is contacted on activation, on page load, or on a schedule — every request follows a
deliberate press, and the GitHub fetches need an administrator to accept a consent prompt first.

No site, user or store data is ever transmitted.
