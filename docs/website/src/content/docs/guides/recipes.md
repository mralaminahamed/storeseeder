title: Recipes
description: Build a whole coherent shop in one click.
---

A recipe is a **vocabulary** — product names, a category tree, brand names, tag labels, a price band
and variation axes — not a dump of records. The generators still build every row, so every invariant
and every existing parameter holds.

Recipes download once from their own repository, behind the consent prompt that already governs the
sample data, so adding a shop type needs no plugin release.

Three ship: `grocery`, `fashion`, `home-garden`.
